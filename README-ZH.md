# TWRP device tree for sprd dove_evb4 (XH026)

这个设备树由 [twrpdtgen](https://github.com/twrpdtgen/twrpdtgen) 生成部分并进行修改

## 下载

点[这里](https://github.com/hxzbaka/Action-TWRP-Builder/releases)，然后搜`CP23NV3`就能找到你的设备了。

如果发现搜到了很多个Releases，请下载最新发布的版本，因为那通常是我修过BUG并进行了适配的完善版本（至少比以前的版本完善）

如果找不到，要么就是没编译，要么就是没编译成。这时候就该自己动手丰衣足食了。

## 构建

可使用[Action TWRP builder](https://github.com/azwhikaru/Action-TWRP-Builder)编译，具体怎么用看它的README.md即可

[Fork](https://github.com/zh-xijun/action-twrp-builder)对于老旧安卓系统有做适配

该设备树相对于源码的存放路径（DEVICE_PATH）：`device/asr/dove_evb4`
